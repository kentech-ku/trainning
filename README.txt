iPhone向け導入手順

1. ZIPを展開し、全ファイルを同じフォルダのままHTTPS対応Webサーバーへ配置します。
2. GitHub Pagesの場合はリポジトリ直下に5ファイルをアップロードし、Settings > Pages > Deploy from a branch を選択します。
3. 公開URLをiPhoneのSafariで開きます。
4. 共有ボタン > ホーム画面に追加 > 追加 を選択します。

注意:
- OneDrive/SharePointのファイルプレビューではService WorkerとlocalStorageが制限される場合があります。
- PWAはHTTPSまたはlocalhostでのみ有効です。
- SafariのWebサイトデータ削除やアプリ削除に備え、履歴画面の「バックアップ出力」を定期利用してください。
